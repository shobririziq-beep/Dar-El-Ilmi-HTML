Apakah website menggunakan Laravel?
Tidak. Website ini menggunakan HTML, CSS, dan JavaScript biasa. Tidak memerlukan Composer, PHP, atau database.
Mengapa setiap halaman memiliki file sendiri?
Karena website ini benar-benar multi-page. Misalnya, Profil menggunakan profil.html dan Perpustakaan menggunakan perpustakaan.html. CSS dan JavaScript dipakai bersama.
Bagaimana cara menjalankannya?
Buka folder proyek di VS Code, lalu klik kanan index.html dan pilih Open with Live Server.
Apakah formulir dapat bekerja tanpa database?
Ya, sebagai simulasi. Data disimpan dalam localStorage browser ini dan dapat dilihat pada halaman Data PPDB.
Apakah data formulir dikirim ke sekolah?
Tidak. Data hanya disimpan di browser. Untuk pendaftaran resmi diperlukan backend, validasi server, dan penyimpanan data yang aman.
Bagaimana cara mengubah tema?
Klik ikon bulan atau matahari di navigasi. Pilihan tema disimpan pada browser.
Apakah gambar dan video memerlukan internet?
Ya. Gambar, font, dan video diambil dari sumber eksternal. Jika koneksi tidak tersedia, media mungkin tidak terlihat.
Apakah nomor pendaftaran merupakan nomor resmi?
Bukan. Nomor hanya dibuat untuk simulasi alur formulir.
